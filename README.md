# 🏆 PENTAS PAI KECAMATAN PAMANUKAN 2026

## Sistem Penilaian Pekan Keterampilan dan Seni Pendidikan Agama Islam

---

### 📋 DESKRIPSI

Aplikasi penilaian digital untuk kegiatan **PENTAS PAI (Pekan Keterampilan dan Seni Pendidikan Agama Islam)** Tingkat Kecamatan Pamanukan Tahun 1447H/2026M.

Aplikasi ini dirancang untuk memudahkan proses penilaian 7 cabang lomba secara **real-time** dan **terpusat** melalui integrasi dengan **Google Sheets**.

---

| No | Kode | Mata Lomba | Tipe |

---

### 👥 PENGGUNA APLIKASI

| Role | Jumlah | Tugas |
|------|--------|-------|
| **Koordinator** | 7 orang | Menilai peserta sesuai mata lomba |
| **Admin** | 3 orang | Melihat rekap semua penilaian |

### 🚀 CARA DEPLOY WEB

1. Upload file `index.html` ke GitHub
2. Buka **Settings > Pages**
3. Pilih branch **main**, folder **root**
4. Klik **Save**
5. Dapat link: `https://username.github.io/pentas-pai-pamanukan-2026/`
